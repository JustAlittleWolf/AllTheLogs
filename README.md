# AllTheLogs

A Fabric client mod for Minecraft **26.2** that allows you to easily search all of your logs.

Messages from logs that were deleted, or when the game was started more than 7 times on a day (see https://bugs.mojang.com/browse/MC/issues/MC-100524) can not be recovered.

## Contributing

Feel free to contribute to this project in any way :)

If you have some logs that are parsed incorrectly (e.g. player or server is not recognized) and have some evidence that this could be parsed correctly, please open an issue or a pull request with the log attached. Chat messages are not valid evidence.
